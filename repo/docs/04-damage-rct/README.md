## Design principles
- Gameplay injury state is separate from visual intensity.
- The server owns injury and limb-function state.
- Client settings can reduce permitted effects but never change gameplay or content maturity.
- Main experience prioritizes stylized, non-graphic presentation.
- Never assume a toggle, fantasy color, or temporary effect changes platform policy.
