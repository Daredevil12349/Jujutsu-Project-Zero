## Principles
- Multiple paths: story, exploration, bosses, training, mastery, and PvP.
- New rewards should unlock decisions or identity, not only percentage increases.
- Death penalty must be clear and recoverable; permanent unlocks are protected.
- Bosses teach combat concepts and support multiple viable responses.
- No pay-to-win, hidden odds, or mandatory reroll grind.
