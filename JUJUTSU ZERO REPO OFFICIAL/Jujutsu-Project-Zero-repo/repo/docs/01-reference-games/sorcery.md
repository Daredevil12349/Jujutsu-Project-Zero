> Do not confuse with *Sorcerer Battlegrounds* (a different JJK battleground game). All facts below are about **Sorcery**.

## 1. Identity (REPORTED)
Roblox action RPG covering PvP, PvE, open-world movement, cursed energy and "technical combat built around timing, defense, and positioning" (G14, allroblox summary). Missions include Savior and Cursed Object missions; Cursed Sense reveals auras; loot drops and a Merchant NPC exist (G14).

## 2. Controls as published (PC; G14; guides from 2024 to 2025)
| Action | Key |
|---|---|
| Basic melee | M1 |
| Heavy / critical | R |
| Block and parry | F (parry = timed press) |
| Dash | Q |
| Dash cancel | M2 while dashing |
| Aerial attack | Space + M1 |
| Uptilt/uppercut | Ctrl + M1 |
| Charge cursed energy | Hold E |
| Draw weapon | T |
| Cursed Sense | N (with E) |
| Movement extras | wall hop, wall run, sprint (Shift), crouch (Ctrl) |
Controller mappings published (L1 dash, R1 interact; L2/R2 aim/fire) (G14).

## 3. Weapons (REPORTED, G16)
Light, medium and heavy classes; each has an M1 string and a "critical" move (e.g. Standard Katana: forward overhead slashes, critical slide-and-upward-strike). Heavy weapons are slow and punishing if blocked or dodged.

## 4. Techniques (REPORTED, G15)
11 cursed techniques at time of the article; Shrine and Limitless called the best (opinion). A Blood Manipulation technique reportedly includes "Blood Reinforce" (level 25), draining CE faster; a Rika summon reportedly blocks, parries and adds M1s.
