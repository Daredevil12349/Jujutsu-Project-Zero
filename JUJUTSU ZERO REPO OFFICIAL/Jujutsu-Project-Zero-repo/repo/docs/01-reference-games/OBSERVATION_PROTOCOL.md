# Observation protocol (for first-hand notes)

Status: TEMPLATE
Purpose: Claude cannot play Roblox games. Anything about feel, atmosphere, animation or audio quality must come from your own play sessions. Use this checklist and paste results back; they will be filed as `OBSERVED`.

## Per session (15 to 20 minutes per game)
Record: game, date, device, ping if known, mode played.

### Combat feel
- [ ] M1 chain: how many hits, rough time per hit, can you cancel? Is there hit-stop (brief freeze on impact)?
- [ ] Block/parry: is parry a separate input? Rough window (easy / tight)? What happens on a missed parry?
- [ ] Dash/dodge: i-frames? cooldown? cancel into attack?
- [ ] Knockback and stagger: can a chain be escaped? Is there a "combo breaker"?
- [ ] Camera: locked-on, shoulder, free? Does it ever fight you?
### Techniques and progression
- [ ] How did you obtain a technique? Time spent? Were odds displayed anywhere?
- [ ] What does a preview/tooltip show before you commit?
- [ ] Anything gated behind Robux that affects power? (note product names/prices)
### Presentation
- [ ] Animation quality: weight, anticipation, recovery (rate 1 to 5 and one sentence).
- [ ] VFX: readability in a crowd? clutter? mobile fallback?
- [ ] SFX: impact sounds, parry sound, Black Flash sound; are they distinct?
- [ ] Atmosphere: lighting, music, UI style; what creates the mood?
### Notes
- Screenshots or short clips are for your reference only; do not redistribute or embed assets.

Output format to paste back: bullet list per section; Claude will file it under `## OBSERVED (date)` in the game's doc.
