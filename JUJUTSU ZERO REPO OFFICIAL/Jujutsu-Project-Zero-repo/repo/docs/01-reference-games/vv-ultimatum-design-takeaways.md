## 1. Why this reference matters

The owner wants Project Zero to combine the intensity and progression depth of a Roblox anime RPG such as VV: Ultimatum with a JJK-inspired sorcery identity, R6 presentation, and a more deliberate Soulslike structure.

VV: Ultimatum is a Bleach-inspired Roblox action RPG, not a JJK game. It is useful as a reference for broad design questions, not as a template to reproduce.

## 2. Reported design elements

The sources consulted describe:
- a timing-focused deflect / block combat foundation;
- light attack strings, heavier posture pressure, counters, and movement tools;
- faction identities with different long-term evolution paths;
- story quests, daily quests, missions, bosses, and faction progression;
- skill trees and abilities that unlock through milestones;
- boss encounters that teach telegraphed attacks and punish windows.

These are secondary reports, not first-hand observations. Verify current behavior in-game before treating any detail as fact.

## 3. What Project Zero should learn

### A. Teach defense early
A safe practice encounter should teach block, perfect block, dodge, and how to identify attacks that cannot be parried. The tutorial should let the player repeat a lesson without losing resources.

### B. Give identity a long arc
Origins should have an early identity, a midgame specialization, and a late-game mastery path. Do not front-load every ultimate ability. The player should feel a meaningful evolution in how they fight.

### C. Make bosses teach the combat system
Use a tutorial boss that introduces readable attacks and a later optional challenge that tests mastery. Bosses should reward observation and adaptation, not just high stats.

### D. Make skill expression visible
High-level play should involve spacing, timing, resource management, punish windows, and matchup knowledge. Movement cancels or advanced tech may exist later, but must be intentional and learnable.

### E. Build progression around several activities
Story, exploration, bosses, training, and PvP should all contribute to long-term goals. Avoid a single optimal grind route that makes the rest of the world irrelevant.

## 4. What Project Zero should avoid

A community critique of VV: Ultimatum describes a perceived over-reliance on parry and M1 loops. This is one opinion, not a verified consensus, but it highlights a risk worth testing: if parry is the best answer to nearly everything, combat becomes repetitive.

Other risks to evaluate in any progression-heavy RPG:
- too many currencies and rerolls,
- long mandatory grind before a signature ability,
- unclear tutorials,
- repetitive enemy farming,
- progression systems that obscure the core combat.

## 5. Project Zero adaptation

| Reference principle | Project Zero adaptation |
|---|---|
| Timing-focused defense | Multiple defense choices: block, parry, dodge, spacing, interrupt |
| Faction progression | Original sorcerer origins with distinct mechanical and narrative arcs |
| Skill-tree identity | Technique mastery that changes decisions, not only damage |
| Boss learning | Bosses teach one or two combat concepts and have fair punish windows |
| Mission loop | Exploration-led districts, investigations, contracts, and boss hunts |
| Advanced movement | R6-compatible movement tech with explicit recovery and counterplay |
