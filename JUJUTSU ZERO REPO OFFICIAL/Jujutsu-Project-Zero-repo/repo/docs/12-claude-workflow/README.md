## Operating expectations
- Read current docs and repository state before work.
- Propose solutions and identify gaps; don't wait for the owner to specify every subtask.
- Separate facts, observations, reports, interpretations, and recommendations.
- Ask only for decisions that materially affect scope, identity, cost, or safety.
- Build one tested vertical slice at a time.
- Report what changed and what was actually verified.
