# JUJUTSU: PROJECT ZERO

# Gameplay Reference Pack

*Curated gameplay, combat, technique, domain and progression references*

**Purpose:** Give Claude a focused set of real Roblox examples to
inspect while designing PROJECT ZERO. This is a research index of links,
not a bundle of downloaded videos or screenshots. Open the references,
capture relevant frames, and attach those images to Claude for visual
analysis.

## How to use this pack

1.  Open a reference and jump to the timestamps listed.
2.  Capture 4--8 frames per mechanic: startup, impact, hit reaction,
    recovery and any visible UI feedback.
3.  Name frames consistently, e.g. `JJI-01_01-startup.png`.
4.  Attach the frames to Claude and ask it to separate direct
    observations from assumptions.
5.  Turn the findings into original PROJECT ZERO design requirements; do
    not copy another game's assets or choreography.

## Frame capture checklist

  -----------------------------------------------------------------------
  Moment                  Capture                 Inspect
  ----------------------- ----------------------- -----------------------
  Startup                 Before the attack       Pose, anticipation,
                          connects                telegraph and camera
                                                  framing

  Impact                  Contact and immediate   Hit confirmation,
                          effect                  flash, particles and
                                                  hit-stop

  Reaction                Target response         Stun, knockback,
                                                  ragdoll, launch
                                                  direction and recovery

  Recovery                Move returns to neutral Endlag and when player
                                                  control resumes

  Context                 HUD and surrounding     Cooldown/resource
                          space                   feedback and crowd
                                                  readability
  -----------------------------------------------------------------------

## Prompt to give Claude with attached frames

> Analyze the attached gameplay reference frames for JUJUTSU: PROJECT
> ZERO. Describe only what is visible and separate observations from
> assumptions. Break the mechanic into startup, impact, target reaction
> and recovery. Assess animation, camera, hit feedback, VFX, any
> audible/described SFX, UI and readability. Explain what makes it
> satisfying and what could improve. Then propose an original Roblox
> implementation covering client presentation, server-authoritative hit
> validation, animation markers, hitbox approach, state changes,
> cooldown/resource handling, VFX/SFX and performance. Do not copy
> names, assets, exact choreography or proprietary code. Do not write
> code until I approve the design brief.
