## Honest limits of this encyclopedia
- **Claude cannot read the manga or watch the anime.** Every "canon" statement below is what a wiki or article **attributes** to a chapter or episode. It is labelled `CANON-MANGA (reported, ch.N)` and carries the source ID. Verify against the primary chapter before building any lore-dependent mechanic.
- Many sources were read only as search excerpts. Pages marked "old revision" may be out of date.
- Anime-only differences have **not** been researched yet; no `ANIME-ONLY` entries exist.
- Spoiler content is fenced with `⚠ MANGA-SPOILER`.

## Label vocabulary (extends PROJECT_RULES.md)
| Label | Meaning here |
|---|---|
| `CANON-MANGA (reported, ch.N)` | A secondary source attributes this to chapter N |
| `CANON-ANIME (reported, ep.N)` | Same for anime (none yet) |
| `⚠ MANGA-SPOILER` | Late-story information |
| `INTERPRETATION` | Author/article reasoning, not stated outright in the work |
| `GAME-ORIGINAL` | Our adaptation; never canon |
| `UNVERIFIED` | Conflicting, undated, or single weak source |
