## Canon basis
| Claim | Label | Source |
|---|---|---|
| A cursed technique is the use or manipulation of CE into a certain technique or pattern; these tend to be unique to the user or their family/clan | `CANON-MANGA (reported, ch.14)` | J02 (old revision) |
| **Inherited technique:** Limitless is passed down in the Gojo clan; Projection Sorcery is the Zenin clan's inherited technique, passed from Naobito to Naoya | `CANON-MANGA (reported)` | J06, J07 |
| **Extension techniques:** Limitless has extensions Cursed Technique Lapse: Blue (increases output and attracts) and Reversal: Red (reverses the technique, producing repulsion/explosive force) | `CANON-MANGA (reported)` | J06, J07 |
| Red's energy output is reported as at least twice Blue's; generating the "positive energy" for Red is described as extremely difficult | `CANON-MANGA (reported)` | J06 |
| **Maximum output:** a chapter summary names "Cursed Technique Lapse: Maximum Cursed Energy Output: Blue" | `CANON-MANGA (reported, ch.71)` | J04 |
| An **exhausted** innate technique is compared to an overheated engine that must cool; Gojo is reported as healing his exhausted technique with Reverse Cursed Technique | `CANON-MANGA (reported, ch.227)` | J05 |
| Yuta's technique "Rika" is a cursed technique activated via an engagement ring, and he can use Reverse Cursed Technique | `CANON-MANGA (reported, ch.178)` | J25 |
| Yuta's Mimicry can copy innate and inherited techniques | `CANON-MANGA (reported)` | J07 |
| Reggie Star's innate technique is Contractual Re-creation | `CANON-MANGA (reported)` | J07 |
| Wiki lists non-innate techniques including Batto Sword Drawing, Curtain, Domain Expansion, Domain Amplification, Evening Moon Sword Drawing, Falling Blossom Emotion, Hazy Moon, Hollow Wicker Basket, Maculation, Simple Domain | `CANON-MANGA (reported)` | J06 navigation box |
| Wiki lists innate techniques including Technique Extinguishment ("Technique"), Ten Shadows Technique, Tool Manipulation (partial list) | `CANON-MANGA (reported)` | J06 navigation box |

## Game adaptation (GAME-ORIGINAL proposal)
| Layer | Proposed use |
|---|---|
| Innate technique | The rolled/acquired base technique slot (docs/08) |
| Inherited technique | Clan-gated variants (docs/08 clan system) |
| Extension technique | Unlocked via mastery nodes on a technique |
| Maximum technique | Costly, high-telegraph signature move, mastery-gated |
| Reversal | Alternate mode of an ability (e.g. attract vs repel) |
| Technique burnout | Soft penalty for overuse (overheat bar), recoverable via RCT |
